# Runout

Android app for [Runout](https://kind-sky-sunny-king.grok.me), the Melbourne bay fishing companion (tide, moon, bite windows).

The APK opens the live Runout site, so forecasts stay current. It needs a network connection.

## Install

1. Open the latest [release](https://github.com/johnsmith86/runout/releases) on your phone.
2. Download `runout.apk`.
3. If Android asks, allow your browser to install apps.
4. Open Runout.

GitHub builds a new APK on every push to `main`. These builds are signed for sideloading. If a later install says the signature does not match, uninstall the old Runout first, then install the new file.
